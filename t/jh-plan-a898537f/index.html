시나리오별 행동

A. 일시불로 갚겠다

가장 좋은 경우
  1. 입금 확인 (아버지 계좌)
  2. 입금 확인 후 7일 안에 가압류 집행해제·취하, 지급명령 취하
  3. 담보취소 동의서·항고권 포기서 받아서 공탁금 500만 회수

B. 나눠서 갚겠다

가능성 가장 큼
  1. 조건: 선지급 크게(절반 이상 목표), 기간 짧게(3~6개월), 한 번 밀리면 남은 돈 전액 즉시
  2. 방법 ① 공증사무소에서 금전채무 공정증서(강제집행 승낙) ② 공증 거부 시 지급명령 이의 안 함 + 합의서 도장
  3. 한정욱 개인 연대보증, 서명하는 날 담보취소 동의서 미리 받기
  4. 가압류는 완납 때까지 유지, 지급명령은 취하하지 않음
  5. 합의서 초안: X31 jh패브릭_사건자료/합의_2026/01_분할변제합의서_초안_v1.md (서명은 아버지 본인)

C. 버틴다 / 이의 낸다

변호사 붙였을 때
  • 가압류 이의: 바로 취소 안 됨. 심문 거치는 동안 통장은 계속 묶임. 근거: 2/27 사과 문자(대표 취임 2일 뒤), 공사 중 본점 이전, 견적서 수신 ㈜JH, 11/5 녹취
  • 지급명령 이의: 일반 소송으로 넘어감. 1억 이하 단독사건이라 법원 허가 받으면 가족이 소송대리 가능
  • 해방공탁 35,673,000원: 통장 풀리지만 공탁금에 가압류가 옮겨붙음 → 오히려 돈 확보
  • 회사 책임이 부정되면 한정욱 개인 책임(무권대리인)으로 청구

D. 연락 끊고 잠수 / 재산 빼돌림

최악의 경우
  • 지급명령 확정 즉시 묶인 은행 본압류·추심
  • 재산명시·재산조회로 다른 계좌·거래처 찾기
  • 거래처 매출채권 압류 (공장 출고 업체 파악) — 압박 효과 가장 큼
  • 사기 고소 검토 (12월 말 기준으로 결정)
